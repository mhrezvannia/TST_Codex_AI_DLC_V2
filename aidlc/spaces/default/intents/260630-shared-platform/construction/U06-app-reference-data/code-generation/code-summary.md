## Key Implementation Decisions

- Browser-facing UI consumes local view models and BFF route handlers only; no browser code contains backend service URLs or direct service calls.
- The local permission state is intentionally read-only so mutation controls render disabled with a visible reason until identity-service authorization integration is available.
- Zod validation helpers are implemented now; React Hook Form integration remains pending because `react-hook-form` is not installed in the current workspace.
- Event status is rendered as text labels, not color-only state, and history/status routes are separate from canonical record reads.
- The workspace uses semantic landmarks, table caption/headers, accessible link/button labels, and a compact operational layout rather than a landing page.

## Test Coverage Summary

- Helper tests cover set descriptor coverage, filtering, permission defaults, and Zod mutation validation.
