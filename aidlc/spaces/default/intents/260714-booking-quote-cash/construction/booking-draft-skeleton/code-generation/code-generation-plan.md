# Code Generation Plan - U01 Booking Draft Skeleton

## Scope and Traceability

U01 implements US-W1-001 and the U01 portions of FR-W1-001, NFR-W1-004, NFR-W1-008, and NFR-W1-009. It creates one contract-shaped Booking draft, lists/reopens it through stable routes, preserves it through guarded migration and restart, and prepares later W1 extension points without implementing validation, pricing, confirmation, or CMM synchronization.

## Guardrails

- Application code is edited in place at workspace root; no duplicate `*_modified` files.
- U01 must not implement or alter the Booking-to-CMM synchronous HTTP path.
- Shared infrastructure is reused; U01 does not invent messaging, caching, or cross-service persistence.
- Test files and test configuration are part of generation, not deferred to Build and Test.
