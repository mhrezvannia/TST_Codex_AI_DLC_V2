## Approval Summary

The plan contains 46 ordered steps. It first builds the closed evidence model
and crash-safe writer, then manager/isolation and migration/restore safety,
commercial scenarios, browser/accessibility evidence, fresh performance,
security/observability/preservation/quality/audits, and finally teardown,
manifest derivation, and operator documentation. Product behavior is treated as
the system under test; U06 does not redesign or extend it.
