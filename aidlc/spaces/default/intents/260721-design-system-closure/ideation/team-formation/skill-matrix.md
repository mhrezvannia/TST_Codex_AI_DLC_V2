## Gaps and Remediation

| Potential gap | Trigger | Remediation |
|---|---|---|
| Hidden semantic reason for a native Booking element | Source/test inspection | Document exception and add regression proof |
| Local browser or Compose prerequisite missing | Preflight command failure | Diagnose in the isolated environment and escalate if external state is required |
| Audit tool invocation unclear | Tool discovery | Read the project skill/instructions before execution |
