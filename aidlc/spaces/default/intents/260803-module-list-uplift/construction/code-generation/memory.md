## Open questions (platform prerequisites)

- 2026-08-11T10:40:00Z — **The edge header-policy include cannot land independently: it would make Reference Data's authorization posture worse, silently.** `apps/reference-data/lib/service-clients.ts` `resolveReferenceDataPermissions` has three fail-open paths: (1) `isLocalAuthBypassEnabled()` returns `canRead+canWrite` on an env flag; (2) the Identity token reference is read from the **browser-suppliable** `authorization` / `x-token-reference` headers; (3) with no token it returns `defaultPermissionState()` = `canRead: true` **without calling Identity at all**. `correlationIdFrom` likewise trusts an inbound `x-correlation-id`. Clearing `Authorization` at the edge — as `component-methods.md` requires — removes path 2 and drops execution into path 3, granting read with no Identity decision. The header include must therefore ship together with U01's authorization rework (current-request Identity decision, no browser-supplied authority, edge-issued correlation), which is blocked on the W2-02 shell. Paths 2 and 3 are direct violations of FR-020, NFR-004, and SEC-U01-15 and exist in current source today, independent of W4.

## Open questions (basePath migration)

- 2026-08-11T10:00:47Z — **The Reference `basePath` migration is confirmed to be U01 work, not a landable prerequisite.** Investigating it surfaced that `apps/reference-data/app/ReferenceDataWorkbench.tsx` issues four root-absolute client fetches (`/api/permissions/reference-data`, `/api/reference-sets/{set}/records` x3). Traced through `infrastructure/nginx/default.conf`, no `/api/permissions` or `/api/reference-sets` location exists, so those requests fall through `location /` to **apps-shell** rather than reaching Reference. They therefore do not work through the canonical edge today and only resolve when the app is reached directly on its own host port. Charge, which already sets `basePath`, correctly calls `/charge-agreements/api/module-info`. Setting `basePath` on Reference would move its server routes under the prefix while those four calls stayed root-absolute, and would also break the `/api/health` container healthcheck added earlier this session (it would become `/reference-data/api/health`, matching Charge's pattern). Landing it correctly requires rewriting the workbench's client calls — which is precisely the canonical-route replacement U01 and U02 specify, and is blocked on the W2-02 shell.
