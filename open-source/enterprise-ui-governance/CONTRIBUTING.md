# Contributing

Thank you for improving Enterprise UI Governance.

## Principles

- Keep `SKILL.md` concise and procedural.
- Put detailed or product-specific guidance in one-level `references/` files.
- Preserve framework neutrality in the core skill.
- Add project profiles instead of hard-coding one product into the core.
- Do not weaken accessibility, evidence integrity, or shared ownership rules.
- Avoid duplicating guidance between `SKILL.md` and references.

## Changes

1. Create a focused branch.
2. Update the skill or the smallest relevant reference.
3. Run the Codex Skill Creator `quick_validate.py` against
   `skills/enterprise-ui-governance`.
4. Verify Markdown fences and links.
5. Explain the user scenario addressed and the behavior change.
