# Security Policy

Do not open a public issue for a vulnerability that could expose credentials,
private repository data, unsafe install behavior, or a way to bypass declared
governance gates.

Report security issues privately through the security-advisory feature of the
GitHub repository hosting this package. Include affected version, reproduction,
impact, and any safe mitigation known to you.

The maintainers will acknowledge a complete report, assess scope, and coordinate
disclosure. No response-time or remediation SLA is promised by this free
open-source project.
